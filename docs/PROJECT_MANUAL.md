# VECV PullChord Dashboard - Client Manual

## 1. Project Overview
This represents a comprehensive Production Dashboard for the VECV Plant. It visualizes real-time Pull Chord data (maintenance calls, line stoppages, etc.) directly from the Shop Floor SQL Server.

## 2. System Architecture (How it Works)

The system consists of three main layers:

```mermaid
graph TD
    subgraph Shop_Floor [Shop Floor Layer]
        A[Machines & PLCs] -->|Writes Data| B((SQL Server DB))
        B -->|Contains| T[Tables: Z3, Z5, Z7, Z9]
    end

    subgraph Server_Layer [Dashboard Application]
        C[Java Spring Boot Server] -->|Queries (Every 30s)| B
        C -->|Calculates KPIs| C
    end

    subgraph User_Layer [Client PC / Large Display]
        D[Web Browser (Chrome/Edge)] -->|Requests Data| C
        D -->|Displays| E[Charts 1-10 & KPIs]
    end
```

## 3. Data Flow Explanation
1.  **Source**: Data is generated by the line operators pulling chords or pressing buttons on the assembly line. This is recorded in the **SQL Server Database**.
2.  **Fetching**: This application ("The Dashboard") connects to the database.
    - **Fast Mode (Recommended)**: It uses a special optimized "Index" to fetch 30-day trends instantly (< 1 second).
    - **Legacy Mode**: It scans the raw text files (slower, ~26 seconds) - useful only for comparison.
3.  **Visualization**: Every **30 seconds**, the dashboard automatically asks the server for the latest numbers. The server sends back a precise summary (JSON), and the browser updates the charts without reloading the page.

## 4. Understanding the Charts
-   **Charts 1-4 (Trends)**: Show the last 30 working days of Breakdowns, MTBF (Reliability), and MTTR (Repair Speed).
-   **Charts 5, 8, 9 (Distributions)**: Show *where* the problems are happening (Which Station? Which Line? Which Shift?).
-   **Charts 6, 7, 10 (Efficiency)**: specific focus on Loss Hours and Uptime %.

## 5. Installation & Running Guide

### A. Prerequisites
-   **Java 17 (JDK)** must be installed on the computer.
-   Access to the **SQL Server** network (The computer must be able to ping the database server).

### B. Running on Windows
1.  Open the project folder.
2.  Double-click the address bar, type `cmd`, and press Enter.
3.  Type the following command and press Enter:
    ```cmd
    mvnw.cmd spring-boot:run
    ```
4.  Wait for the message: `Tomcat started on port 8070`.
5.  Open your browser (Chrome/Edge) and go to: `http://localhost:8070`

### C. Running on Mac/Linux
1.  Open Terminal.
2.  Navigate to the project folder (`cd path/to/folder`).
3.  Run:
    ```bash
    ./mvnw spring-boot:run
    ```
4.  Open `http://localhost:8070` in your browser.

## 6. Troubleshooting
-   **Red Status Dot**: The dashboard cannot reach the server or database. Check your network connection.
-   **Empty Charts**: If the database has no data for the selected table, charts will be empty. Try selecting a different table from the "Configuration" menu.
-   **Slow Loading**: Ensure the "Performance Mode" toggle in the top right is set to **Fast (Green)**.
